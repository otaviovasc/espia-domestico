# Componentes de registry para o painel Espia Doméstico

Pesquisa em fontes primárias em **15/10/2026**. Escopo: painel autenticado, login e ferramentas; páginas públicas excluídas. Este documento recomenda componentes e adaptações; nenhum pacote foi instalado e nenhuma integração foi validada em runtime nesta pesquisa.

## Decisão proposta

Usar **Base UI + componentes de fonte própria** como base operacional, aproveitando exemplos ReUI/shadcn e Dice UI. É a combinação com maior reaproveitamento entre seleção pesquisável, dialog/drawer e upload. Reservar Motion para um indicador de abas e confirmação de ação, se o ganho justificar a dependência. Não instalar bibliotecas inteiras para reproduzir um efeito.

O app usa React 19.2, Tailwind 4.1 e Vite 7. A compatibilidade declarada ou inferida das fontes abaixo **não equivale a build e teste no app**. Base UI é sem estilo; ReUI declara React 19/Tailwind 4, e os itens shadcn selecionados possuem fontes específicas v4. [Pré-requisitos ReUI](https://reui.io/docs/get-started), [Base UI npm: peers React 17/18/19](https://registry.npmjs.org/@base-ui/react/latest).

## Teclado e movimento: evidência e ajustes necessários

- **Combobox:** a primitiva Base UI gerencia input/listbox, highlight e seleção. Usar rótulo visível, clear com nome acessível, vazio explícito e ID estável para valores vindos de refetch. A documentação traz integração de resultados assíncronos; o exemplo ReUI de 100 opções é local e **não implementa busca remota/paginação**. No Compose, manter TanStack Query e busca limitada; não carregar catálogo inteiro para alimentar o seletor. Testar setas, Enter, Escape e remoção de chips. [API e exemplos Base UI](https://base-ui.com/react/components/combobox), [notas específicas ReUI](https://reui.io/components/combobox.md).
- **Tabs:** Radix documenta Tab, setas, Home/End e ativação automática/manual. Usar ativação manual se a troca dispara trabalho caro; filtro de uma tabela não vira tab sem painel associado. [Teclado Radix Tabs](https://www.radix-ui.com/primitives/docs/components/tabs#keyboard-interactions).
- **Sheet/Dialog:** Radix documenta foco contido, Escape e retorno ao trigger; a primitiva fornece o mecanismo, mas composição e ações continuam sendo responsabilidade do app. No Dice/Base UI, verificar os mesmos comportamentos no componente composto, inclusive teclado virtual no drawer mobile. [Radix Dialog](https://www.radix-ui.com/primitives/docs/components/dialog), [Base UI Dialog](https://base-ui.com/react/components/dialog), [Base UI Drawer](https://base-ui.com/react/components/drawer).
- **Animate UI:** a recomendação oficial é `MotionConfig reducedMotion="user"`; não há garantia de preferência respeitada apenas ao copiar o componente. Transform/layout são tratados por essa configuração; conferir animações explícitas de altura e usar duração zero quando necessário. [Acessibilidade oficial](https://animate-ui.com/docs/accessibility), [fonte AutoHeight com `animate={{ height }}`](https://animate-ui.com/r/primitives-effects-auto-height.json).
- **Sonner:** fonte usa live region `polite` e atalho padrão Alt+T para foco; ações são botões. CSS oficial desliga animation/transition em reduced motion. Traduzir labels e manter erro relevante também junto do campo/ação; toast que expira não pode ser o único caminho de recuperação. [Fonte](https://github.com/emilkowalski/sonner/blob/main/src/index.tsx), [CSS](https://github.com/emilkowalski/sonner/blob/main/src/styles.css).
- **Cult Halo Button:** fonte consulta `useReducedMotion` e desabilita controle no pending. Ainda testar anúncio do estado e estabilidade de largura com textos reais em português; `aria-busy` não produz mensagem de sucesso por si só. [Registry com fonte](https://cult-ui.com/r/halo-button.json).
- **Dice Upload:** fonte trata Enter/Espaço no dropzone, associa input/lista, expõe invalidez e progresso por ARIA. Transições CSS não têm tratamento de reduced motion demonstrado nesse item; adicionar regra local. Ações de remover devem ter nomes com o arquivo correspondente. [Fonte completa](https://diceui.com/r/base-nova/file-upload.json).
- **Empty:** estrutura é visual, com título renderizado como `div` na fonte; compor heading semântico e CTA real no app. Nenhuma região viva automática foi demonstrada. [Fonte](https://ui.shadcn.com/r/styles/new-york-v4/empty.json).

## Estilo neo brutalista arredondado

Aplicar sobre os tokens compartilhados, preservando a distinção de superfície, texto, accent e estados. Proposta: raios 10–12px em controles, 16–20px em painéis/dialogs; borda estrutural 1.5–2px; sombra seca curta de 2–3px somente em ações e superfícies elevadas. Pressionar reduz a sombra e desloca 1px; 120–160ms, sem bounce. Em reduced motion, remover deslocamento e conservar apenas mudança de estado/cor. Estas são decisões de design para o produto, não garantias das bibliotecas.

O verde operacional mantém coerência com distribuição WhatsApp; um acento amarelo quente pode diferenciar seleção/foco editorial, sempre derivado da paleta aprovada pelo responsável visual e com contraste medido em ambos os temas. Não trocar a paleta por tema padrão do registry. Produto, preço e mensagem continuam sendo o conteúdo dominante. Descartar gradient rim do Cult, flip teatral dos dialogs e altura animada de páginas inteiras; aproveitar estado e mecanismo de interação.

## Duas integrações imediatas

1. **ReUI/Shadcn Base Combobox controlado para destinos do Compose.** Adaptar exemplo 12 para IDs dos grupos e mostrar contagem/resumo acessível. Busca local somente para lista já disponível e limitada; manter paginação/query existente para produtos. Critério: seleção persiste ao filtrar/refetch, teclado funciona, vazio/loading/erro são distintos e mobile não transborda.
2. **Dialog/Sheet de uma única família Base UI para preview e navegação mobile.** Começar pelo preview antes de envio e drawer do shell, usando composição de fonte shadcn/Dice. Critério: foco entra e fica contido, Escape e botão Fechar funcionam, foco retorna, scroll de fundo bloqueia, rascunho sobrevive ao fechar/resize e reduced motion remove deslocamentos. Adicionar indicador de aba por Motion somente depois dessa base passar.

## Cobertura da pesquisa

MCP shadcn `get_project_registries` respondeu sem registros configurados; `view_items_in_registries` leu `@shadcn/tabs`, `sonner`, `empty`, `spinner`. Busca MCP em namespaces externos respondeu `NOT_CONFIGURED`; por isso os itens externos foram conferidos diretamente nos JSONs públicos e docs/source primários, sem mudar configuração. [Índice canônico de registries](https://ui.shadcn.com/r/registries.json) confirmou `@animate-ui`, `@cult-ui`, `@diceui`, `@reui` e seus templates de URL.

Fontes e manifests foram inspecionados; não houve instalação, medição de bundle, teste de acessibilidade no browser nem integração com API. Próximo passo verificável: implementar as duas composições prioritárias e validar no app a 390px/desktop, light/dark, teclado e reduced motion.
