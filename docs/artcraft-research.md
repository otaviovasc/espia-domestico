# ArtCraft source research

Checked against first-party pages and GitHub APIs on 2026-10-14 23:03 UTC. This is a bounded audit of the projects linked by the current website. Source descriptions below are upstream claims unless a specific source module is noted. No upstream binaries were executed.

## What the website actually links

[ArtCraft](https://getartcraft.com/) links the [main ArtCraft studio](https://github.com/storytold/artcraft). Its [Craft Apps page](https://getartcraft.com/apps) lists exactly thirteen separate creative applications, plus a [launcher](https://github.com/storytold/craft-launcher). This is a first-party app family, not an aggregator of unrelated open-source launches. The page labels three apps early alpha and ten in development. FilmCraft advertises desktop support; the other twelve also advertise browser/WebAssembly builds. Availability is not evidence of production readiness.

## Ranked integration recommendations

The current platform is a React/TypeScript frontend and Node/TypeScript backend with FFmpeg exports. The upstream apps are full Rust workspaces with desktop frontends. These recommendations adapt useful behavior into the existing editor. They do not imply that an upstream editor, codec or WASM bundle has been embedded.

| Rank | Source family | Concrete addition here | Implementation and verification boundary |
|---|---|---|---|
| 1 | PhotoCraft + LightCraft | Non-destructive exposure/brightness, contrast, saturation; reset, before/after, apply corrections across scenes/slides | Persist bounded settings in project JSON. Use identical formulas/order in browser and FFmpeg. Compare rendered fixtures with preview and verify originals remain intact. |
| 2 | DeckCraft + DesignCraft | Reusable brand colors, title/price/CTA templates, carousel layouts, text overflow and missing-media checks | Build original templates around existing text/image layers. Preserve per-slide overrides. Check all placement ratios and long Portuguese copy. |
| 3 | FigCraft + VectorCraft | Fit/fill modes, focal point, placement sizes, consistent margins and alignment | Represent frame geometry explicitly. Apply the same crop and position math to frontend preview and backend render. Do not call a placement preset automatic reframing. |
| 4 | FilmCraft + SoundCraft | Audio gain, fades, LUFS/true-peak normalization, clear export audio choices | Use existing FFmpeg filters rather than importing a native DAW. Verify tone/impulse fixtures and probe rendered outputs. Source audio, music-only and mute must be distinct controls. |
| 5 | EffectCraft | Original motion-title/CTA presets, deterministic easing, hold/linear/Bezier options | Share timing/easing definitions or reference fixtures between browser and backend. Support a small explicit preset list; do not advertise arbitrary keyframe graphs or Lottie until implemented. |
| 6 | GridCraft + WordCraft | Structured CSV/JSON product merge, reusable copy tokens, catalog-to-carousel starter | Reuse existing saved-product data; generate editable slides with deterministic ordering. Report missing fields and preserve manual edits when refreshing product data. |
| 7 | FilmCraft | Destination export presets, exact duration/frame snapping, render checklist | Separate output aspect/size from Instagram publishing. Check scene duration, transition overlap, final frame and playable codec metadata. |
| 8 | PdfCraft + LightCraft | Downloadable review manifest/contact sheet and numbered carousel package | Begin with self-contained HTML/JSON and existing ZIP export. PDF support requires an actual renderer plus visual verification. |
| 9 | CADCraft | Precise geometry/alignment principles | CAD importing, DXF, 3D drafting and engineering tooling do not address the current ads workflow. Use snapping ideas only when the editor gains freeform layer manipulation. |

## Source mechanisms inspected

- [filmcraft/crates/time/src/lib.rs](https://github.com/storytold/filmcraft/blob/0b432e3834f983d03b2a324c8953522ddda22b57/crates/time/src/lib.rs): Integer timebase: `Tick(i64)` with 254,016,000,000 ticks/second, rational frame rates and frame snapping. In TypeScript, retain integer frames or BigInt if adopting this large tick rate; ordinary Number integers overflow after about 9.8 hours.
- [effectcraft/crates/keyframe/src/lib.rs](https://github.com/storytold/effectcraft/blob/05955c08b4fd025f1a09882df72e6dbff1a8148a/crates/keyframe/src/lib.rs): Temporal interpolation: linear, Bezier and hold. The source exposes `ease_progress`, `evaluate`, `segment_value`, `velocity` and `easy_ease`. Spatial paths use their own arc-length tables.
- [soundcraft/crates/dsp/src/lib.rs](https://github.com/storytold/soundcraft/blob/3a28a657692c1b98b28c276d8f61df9471074f0f/crates/dsp/src/lib.rs): Original DSP facade includes peak/RMS/BS.1770 metering, offline processing, plugin descriptors and bounded parameter handling. Native plugin hosting is separate from basic gain/fade controls.
- [figcraft/crates/layout/src/lib.rs](https://github.com/storytold/figcraft/blob/833f0d2c27f0acbae5394848930ae531fc89c724/crates/layout/src/lib.rs): Auto-layout implementation separates fixed/hug/fill sizing and resize constraints. Text measurement is injected instead of coupling layout to fonts.
- [designcraft/crates/engine/src/sample.rs](https://github.com/storytold/designcraft/blob/d07cbbe94c2762865eaefeff4ebfd1dbada180a0/crates/engine/src/sample.rs): The sample page layouts use original text and imagery generated in code. This is a useful model for creating original ad templates without copying branded screenshots.

The [FilmCraft architecture](https://github.com/storytold/filmcraft/blob/0b432e3834f983d03b2a324c8953522ddda22b57/docs/architecture.md) and [EffectCraft architecture](https://github.com/storytold/effectcraft/blob/05955c08b4fd025f1a09882df72e6dbff1a8148a/docs/architecture.md) separate immutable project snapshots, commands, render evaluation and export. Their common automation idea is one typed command registry shared by UI, CLI and agent integrations. A later platform command API should use this separation; importing their MCP server does not make our existing browser editor automatable.

## Reuse rules

- For copied or ported source from the thirteen apps, select MIT or Apache-2.0 explicitly and retain the required copyright/license notices. Under Apache-2.0, retain applicable notices (including upstream `NOTICE`) and mark modified files. Review each imported file and dependency, rather than assigning a whole repository one license from GitHub metadata.
- The READMEs exclude ArtCraft names and logos from the code licenses. Their brand license permits only unmodified use as part of the upstream app/repository. Do not place ArtCraft marks, logos, or branded screenshots in our editor or templates.
- Fonts, icons, images, fixtures and other assets have separate licenses documented in upstream `ATTRIBUTION.md`, `assets/ATTRIBUTION.md` (LightCraft), or `ASSETS.md`. Prefer our own generated templates and existing licensed assets. A code license does not grant rights to all sample media.
- Generated AI media and model access remain separate from source licensing. No API keys, subscription credentials, paid model calls, sample-video collection or remote provider sign-in were used during this audit.
- Feature inspiration alone is distinct from copied/ported source. Describe what was independently implemented here, and do not claim an upstream application was imported if only behavior was adapted.

Example pinned legal sources: [PhotoCraft README](https://github.com/storytold/photocraft/blob/98fc6ab0722465ad6167946b389333e7fc01a4db/README.md), [MIT](https://github.com/storytold/photocraft/blob/98fc6ab0722465ad6167946b389333e7fc01a4db/LICENSE-MIT), [Apache-2.0](https://github.com/storytold/photocraft/blob/98fc6ab0722465ad6167946b389333e7fc01a4db/LICENSE-APACHE), [brand license](https://github.com/storytold/photocraft/blob/98fc6ab0722465ad6167946b389333e7fc01a4db/docs/brand/LICENSE-brand.txt), [asset attribution](https://github.com/storytold/photocraft/blob/98fc6ab0722465ad6167946b389333e7fc01a4db/ATTRIBUTION.md).

## Iteration order and limits

1. Implement bounded corrections, crop/fit controls and brand/layout recipes; verify preview/render parity and project round trips.
2. Add deterministic motion and audio controls; verify frame/duration and output-audio fixtures.
3. Add product-data merge, preflight and review/package exports; exercise editing, duplication, reload and mixed image/video carousels.
4. Only then evaluate a pinned native CLI or self-hosted WASM editor as an optional separate tool. Verify release checksums, hosting restrictions, actual format support, accessible controls and capability failures before enabling it.

This report verifies website inventory, public repository/license evidence, source pins, documented feature relevance and selected mechanism source. It does not certify the thirteen editors, their claimed parity percentages, their codecs, release binaries, browser builds or full third-party dependency licenses. No Rust build, upstream regression suite, paid rendering or deployment occurred. Platform implementation and runtime results belong in the implementation handoff rather than this source audit.
