# Espiã wordmark font

Bricolage Grotesque, by Mathieu Triay / The Bricolage Grotesque Project Authors.
Used only by the Espiã Doméstico logo; the product's body and heading fonts remain independent.

The Latin variable WOFF2 is self-hosted, unmodified, and includes the accented letters in “Doméstico”.
Weight range: 200–800; optical size: 12–96. SIL Open Font License 1.1 is included in `OFL.txt`.

Primary sources, retrieved 2026-10-15:
